
# ALLINO — Style Yourself 🛍️

### A Modern Fashion & Lifestyle E-Commerce Website

ALLINO is a responsive fashion e-commerce web application built with React.js. It provides a modern shopping experience with stylish product collections, interactive product details, wishlist management, and a shopping cart.

The project focuses on creating an elegant, user-friendly interface with smooth animations, responsive layouts, and seamless navigation.

## 🌐 Live Demo

**Website:** [ALLINO — Style Yourself](https://allino-styleyourself.vercel.app/)

> Note: Replace this link if Vercel assigns a different deployment URL.

## ✨ Features

- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Product Collections:** Browse Clothing, Footwear, Jewelry, Bags, Accessories, and Beauty.
- **Product Details:** View product information, pricing, available options, and quantity controls.
- **Size & Color Selection:** Select product variants where applicable.
- **Shopping Cart:** Add or remove products, update quantities, and view order totals.
- **Wishlist:** Save favorite products for later.
- **Product Filtering:** Explore products by collection and subcategory.
- **Price Sorting:** Sort products by price and other available options.
- **Interactive UI:** Smooth animations powered by Framer Motion.
- **Persistent Shopping Data:** Cart and wishlist data are saved using browser localStorage.
- **Order Summary:** View subtotal, shipping estimates, and total amount.

## 🛒 Shopping Experience

Customers can browse fashion collections, explore individual products, select applicable sizes and colors, and add items to their shopping bag.

The cart displays selected product options, quantity controls, item totals, and an order summary.

Wishlist functionality allows customers to save and manage their favorite products.

Shopping cart and wishlist information persists in the browser using localStorage.

## ⚠️ Current Limitations

ALLINO is currently a frontend-focused e-commerce project.

- Product data is maintained locally.
- Cart and wishlist information is stored in browser localStorage.
- Product availability and variant selections are not connected to a live inventory system.
- The payment gateway is not yet integrated.
- Checkout does not currently process real transactions.
